# ImpulseLock — V1 Documentation

This folder documents the current (V1) state of the ImpulseLock codebase as it exists in this repository: a Spring Boot backend that evaluates financial transactions against a rule-based risk engine, and a React frontend for entering preferences/transactions and viewing decisions.

This documentation was generated by reading the source code directly (backend Java sources, frontend JS sources, `pom.xml`, `application.properties`, `README.md`). It describes what the code *does*, not an aspirational spec — where behavior is surprising or incomplete, it is called out explicitly rather than smoothed over.

## Quick facts

- **Backend**: Java 17, Spring Boot 4.0.2 (`spring-boot-starter-web`, `spring-boot-starter-jdbc`), MySQL via `mysql-connector-j`, Maven build. No JPA/Hibernate — raw JDBC via `JdbcTemplate`.
- **Frontend**: React 19 (Create React App / `react-scripts` 5.0.1), no router, no external state management library.
- **Database**: MySQL, two tables (`users`, `transactions`), no migration tooling (`spring.sql.init.mode=never`) — schema must be created by hand.
- **Package root**: `com.impulselock.impulselock`.
- **Ports**: backend `8080`, frontend dev server `3000`.
